# DJTUBE

[https://s.cympfh.cc/djtube/](https://s.cympfh.cc/djtube/) を開く。デッキ A と B に曲を載せて、混ぜて再生する。

画面下に同じキーが出る。検索欄にフォーカスがあるあいだ、文字キーは検索語になる。`Enter`、`↑` / `↓`、`Esc` だけが操作になる。

## 検索

曲名やアーティストを入れて「検索」を押す。`/` で検索欄に入り、`Enter` で検索する。

「音楽に限る」は最初オン。チェックを外すと、音楽以外も検索できる。`M` で切り替える。検索語が残っているときは、切り替えた設定でもう一度検索する。検索欄の中では `M` は文字になる。

`↑` / `K` で結果を上へ、`↓` / `J` で下へ。検索欄の中では `↑` と `↓` だけが結果を動かし、`J` と `K` は文字になる。`Esc` で検索欄から抜ける。

## ロード

結果を選んで、デッキ A か B に載せる。載せているあいだ、その曲の絵がデッキに出る。絵が無い曲は、その場所が空のまま。

- `A` で選択中の曲をデッキ A へ
- `B` で選択中の曲をデッキ B へ
- `T`、または「次のロード先」の A / B で、次に載せるデッキを切り替える
- 検索欄の外で `Enter` を押すと、そのロード先に載せる。同じ語のまま検索欄にいるときは、結果が出たあとにもう一度 `Enter` で載せる

## プレイリスト

名前を付けた曲の並び。ページを開き直しても、別のブラウザで開いても、同じ並びが出る。

名前欄に名前を入れて「作る」。`P` で名前欄に入る。名前欄で `Enter` を押すと作る。`Esc` で名前欄から抜ける。名前欄にいるあいだ、文字キーは名前になる。`Enter` と `Esc` だけが操作になる。

`Shift+P` で、今のプレイリストの名前を名前欄に入れる。その状態で `Enter` を押すと名前を変える。「変える」でも、名前欄の文字を今のプレイリストの名前にする。

一覧からプレイリストを選ぶ。`PageUp` / `PageDown` で前後のプレイリストに移る。

`Shift+Backspace` または `Shift+Delete` で、今のプレイリストを消す。

曲を足す。

- `L` で、選択中の検索結果を足す
- `S` で、デッキ A に載っている曲を足す
- `Shift+S` で、デッキ B に載っている曲を足す

プレイリストの中の曲。

- `G` / `Shift+G` で上へ / 下へ選ぶ
- `5` / `6` で、選んでいる曲の順番を上げる / 下げる
- `Backspace` または `Delete` で、選んでいる曲を外す
- `Shift+A` でデッキ A へ、`Shift+B` でデッキ B へ載せる。載せ方は検索結果と同じ

検索欄にいるあいだ、これらのキーは操作にならない。文字キーは検索語のまま。

## 再生

デッキの「再生」を押す。もう一度押すと止まる。

- `Q` はデッキ A
- `W` はデッキ B

## テンポ

各デッキの再生速度。1.00× が等速。0.50× から 2.00× のあいだを滑らかに動く。曲を載せると、そのデッキのテンポは 1.0 に戻る。もう一方のデッキの速度はそのまま。

- `1` / `2` でデッキ A を下げる / 上げる
- `3` でデッキ A を 1.00× に戻す
- `8` / `9` でデッキ B を下げる / 上げる
- `0` でデッキ B を 1.00× に戻す

「1.0 に戻す」でも等速に戻る。

FLX4 のテンポスライダーは、左がデッキ A、右がデッキ B の再生速度を、0.50× から 2.00× のあいだで滑らかに動かす。

## キュー

各デッキのキュー位置は、最初は曲の先頭。

「キュー」を押す。

- 再生中なら、キュー位置へ戻して止まる
- 止まっていて、キュー位置にいないなら、そこへ戻って止まったまま
- キュー位置で止まっているなら、再生する

`Z` がデッキ A、`X` がデッキ B。

`Shift+Z` / `Shift+X` で、今の再生位置をそのデッキのキュー位置にする。

## ジョグ

再生位置だけを動かす。キュー位置とクロスフェーダーは変わらない。曲の端より外には動かない。デッキに曲が載るまでは動かない。

- `[` / `]` でデッキ A を約 1 秒戻す / 進める
- `Shift+[` / `Shift+]` でデッキ A を約 10 秒
- `;` / `'` でデッキ B を約 1 秒戻す / 進める
- `Shift+;`（`+`） / `Shift+'` でデッキ B を約 10 秒

デッキの時間のバーをクリックしても、その位置へ移る。

## クロスフェーダー

中央のフェーダーで、A と B の混ざりを変える。左が A、右が B。画面の「位置」がフェーダーの位置、「音量」が各デッキの大きさ。

- `←` / `,` で A 側へ
- `→` / `.` で B 側へ
- `Shift+←` / `Shift+→` で大きく動かす
- `Home` / `End` で A 端 / B 端へ

## イコライザー

各デッキの HIGH / MID / LOW。中央が 0 dB。左がカット、右がブースト。バンドの「0 dB」でそのバンドだけ戻す。曲を載せると、そのデッキのイコライザーは中央に戻る。もう一方のデッキのイコライザーはそのまま。

FLX4 の HI、MID、LOW は、左がデッキ A、右がデッキ B。中央が 0 dB。

デッキ A

- `E` / `R` で HIGH を下げる / 上げる
- `D` / `F` で MID を下げる / 上げる
- `C` / `V` で LOW を下げる / 上げる
- `4` で 3 バンドを 0 dB に戻す

デッキ B

- `I` / `O` で HIGH を下げる / 上げる
- `Y` / `U` で MID を下げる / 上げる
- `N` / `H` で LOW を下げる / 上げる
- `7` で 3 バンドを 0 dB に戻す

スライダーにフォーカスがあるあいだは、左右の矢印でそのバンドだけ動く。
