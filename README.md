# DJTUBE

ブラウザだけで遊ぶ、YouTube 版の 2 デッキ DJ トイです。曲を検索してデッキ A と B に載せ、再生・キュー・クロスフェーダーをキーボードだけで操作できます。音はページ内の YouTube プレーヤー（IFrame Player API）から出ます。

配信先 [https://s.cympfh.cc/djtube](https://s.cympfh.cc/djtube) に合わせ、アセットのベースパスは `/djtube/` です。サーバーは不要で、`dist/` をそのパスに置く静的ファイルとして動きます。

## ローカルでの起動

Node.js 20 以上が必要です。

```bash
npm install
npm run dev
```

http://localhost:5173/djtube/ を開きます。

本番と同じビルドを確認するときは次のとおりです。

```bash
npm run build
npm run preview
```

プレビューは http://localhost:4173/djtube/ です。`npm test` でキーボード割り当てと、コントローラー変換のテストが走ります。

## キーボード

画面下にも同じキーを出しています。検索欄にフォーカスがあるあいだ、文字キーは検索語の入力です。`Enter` で検索するとフォーカスが外れ、以降のキーはデッキ操作になります。`/` でもう一度検索欄へ戻れます。`Esc` でも検索欄から外れます。

| キー | 操作 |
| --- | --- |
| `/` | 検索欄へフォーカス |
| `Enter` | 検索欄では検索を実行。外では選択中の曲を次のロード先へ載せる |
| `↑` `↓` | 検索結果の選択を移動（検索欄にいるときも動く） |
| `A` | 選択中の曲をデッキ A へロード |
| `B` | 選択中の曲をデッキ B へロード |
| `T` | 次のロード先を A と B で切り替え |
| `Q` | デッキ A の再生 / 一時停止 |
| `W` | デッキ A をキュー地点へ戻して停止 |
| `Shift`+`W` | デッキ A のキュー地点を今の再生位置にする |
| `O` | デッキ B の再生 / 一時停止 |
| `P` | デッキ B をキュー地点へ戻して停止 |
| `Shift`+`P` | デッキ B のキュー地点を今の再生位置にする |
| `Space` | 次のロード先デッキの再生 / 一時停止 |
| `←` `→` | クロスフェーダーを A 側 / B 側へ少し動かす |
| `Esc` | 検索欄からフォーカスを外す |

マウスでも検索、結果の `A` / `B`、各デッキのボタン、フェーダーを操作できます。どれもキーボードと同じアクションに入ります。

検索は、静的ページから YouTube Data API を叩けないため、公開の Piped と Invidious インスタンス経由で動画 ID を取ります。再生そのものは YouTube IFrame Player API です。インスタンスが落ちているときは検索だけ失敗することがあります。埋め込みが禁止されている動画や、YouTube が再生前の確認を求める場合は、プレーヤー側で止まります。

クロスフェーダーは等パワーです。中央でも各デッキの音量は 100 ではなく約 71 になります。

## DDJ-FLX4

Pioneer DJ DDJ-FLX4 の MIDI 割り当てはまだありません。コントローラーを接続しても、いまはデッキは動きません。

あとから足せるように、入力の入口だけ分けてあります。

- 割り当て表は `src/input/controller.ts` の `flx4Bindings`（意図的に空）
- MIDI メッセージをアプリのアクションへ変える関数は、同じファイルの `midiMessageToAction`
- キーボードもマウスもコントローラーも、最終的には `src/dispatch.ts` の `dispatch` に同じアクションを渡す

FLX4 のノート番号や CC を `flx4Bindings` に足せば、デッキやプレーヤーを書き換えずに繋げます。画面の「MIDI入力を有効化」はその受信口を開くだけで、割り当ては入りません。
