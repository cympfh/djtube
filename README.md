# DJTUBE

[https://s.cympfh.cc/djtube/](https://s.cympfh.cc/djtube/) を開く。デッキ A と B に曲を載せて、混ぜて再生する。

画面下に同じキーが出る。検索欄にフォーカスがあるあいだ、文字キーは検索語になる。`Enter`、`↑` / `↓`、`Esc` だけが操作になる。

## 検索

曲名やアーティストを入れて「検索」を押す。`/` で検索欄に入り、`Enter` で検索する。YouTube の URL か動画 ID を入れて検索すると、その曲だけが出る。

「音楽に限る」は最初オン。チェックを外すと、音楽以外も検索できる。`M` で切り替える。検索語が残っているときは、切り替えた設定でもう一度検索する。検索欄の中では `M` は文字になる。

`↑` / `K` で結果を上へ、`↓` / `J` で下へ。検索欄の中では `↑` と `↓` だけが結果を動かし、`J` と `K` は文字になる。`Esc` で検索欄から抜ける。

FLX4 の中央上のノブは、右回りで下の曲、左回りで上の曲。`J` / `K` と同じ。プレイリストのタブでも、同じ向きに選ぶ。

結果の各曲に「Aへ」「Bへ」「プレイリスト追加」がある。「Aへ」「Bへ」は、そのデッキに載せる。「プレイリスト追加」を押すと、作ってあるプレイリストの一覧が出る。選ぶと、その曲がそのプレイリストに足される。プレイリストが無いときは、「プレイリストがありません」と出て、追加できない。

## ロード

結果を選んで、デッキ A か B に載せる。載せているあいだ、その曲の絵がデッキに出る。絵が無い曲は、その場所が空のまま。

- `A` で選択中の曲をデッキ A へ
- `B` で選択中の曲をデッキ B へ

FLX4 の LOAD は、見ている一覧で選んでいる曲をデッキに載せる。デッキ 1 が A、デッキ 2 が B。プレイリストのタブでは、その並びの曲。

## プレイリスト

名前を付けた曲の並び。ページを開き直しても、別のブラウザで開いても、同じ並びが出る。

検索とプレイリストはタブで切り替える。開いたときは検索。

プレイリストのタブで、作ってあるプレイリストを選ぶと中身が出る。各曲の「Aへ」「Bへ」で、そのデッキに載せる。載せ方は検索結果と同じ。「削除」を一度押すとボタンが「本当に削除？」になり、もう一度押すとその曲だけ外れる。

名前欄に名前を入れて「作る」。`P` で名前欄に入る。名前欄で `Enter` を押すと作る。`Esc` で名前欄から抜ける。名前欄にいるあいだ、文字キーは名前になる。`Enter` と `Esc` だけが操作になる。

プルダウンの下の「編集」を押すと、「リネーム」と「プレイリスト削除」が出る。「リネーム」は名前を直して、今選んでいるプレイリストの名前を変える。「プレイリスト削除」は、今選んでいるプレイリストを消す。曲の「削除」とは別。

`Shift+P` で、今のプレイリストの名前を名前欄に入れる。その状態で `Enter` を押すと名前を変える。

`PageUp` / `PageDown` で前後のプレイリストに移る。

`Shift+Backspace` または `Shift+Delete` で、今のプレイリストを消す。

- `L` で、選択中の検索結果を足す
- `S` で、デッキ A に載っている曲を足す
- `Shift+S` で、デッキ B に載っている曲を足す

プレイリストの中の曲。

- `↑` / `K` で上へ、`↓` / `J` で下へ。検索結果と同じ。中央上のノブも、右回りで下、左回りで上
- `G` / `Shift+G` で上へ / 下へ選ぶ
- `5` / `6` で、選んでいる曲の順番を上げる / 下げる
- 曲の絵の左を掴んでドラッグすると、離した位置にその曲の順番が移る
- `Backspace` または `Delete` で、選んでいる曲を外す
- `Shift+A` でデッキ A へ、`Shift+B` でデッキ B へ載せる。載せ方は検索結果と同じ

検索欄にいるあいだ、これらのキーは操作にならない。文字キーは検索語のまま。

## 再生

デッキの「再生」を押す。もう一度押すと止まる。再生中は、そのデッキの絵の上に薄い白い輪が回り、輪の印の向きで回りが分かる。テンポに合わせて速さが変わる。止めたときと、曲が入っていないときは回らない。デッキ A と B は別々に回る。

- `Q` はデッキ A
- `W` はデッキ B

音源が取れないと「音源を再生できませんでした」と出て、そのデッキの「再生」は押せない。`Q` と `W` も、そのデッキでは再生を始めない。エラーが消えて別の曲を載せると、また再生できる。もう一方のデッキはそのまま。

## Cookie

画面上部の丸い Cookie の印を押すと、ファイルのアップロードと貼り付けが出る。保存してある Cookie は、再生が失敗する前でも、ここで差し替えられる。

YouTube へのサインインが要るために音源が再生できないときも、画面に Cookie の書き出し方と、ファイルのアップロードと貼り付けが出る。それ以外の失敗では出ない。

1. ブラウザで YouTube を開き、サインインする。
2. サインインしたまま、Cookie を Netscape 形式のファイルに書き出す。Chrome、Edge、Firefox では、拡張機能「Get cookies.txt LOCALLY」を入れ、YouTube のページで書き出す。
3. 画面上部の丸い Cookie の印でそのファイルを選んでアップロードするか、ファイルの中身を貼り付けて保存する。

切れたら、同じ手順で書き出して、画面上部の丸い Cookie の印からファイルを差し替えるか、中身を貼り付けて保存する。

## テンポ

各デッキの再生速度。1.00× が等速。0.50× から 2.00× のあいだを滑らかに動く。曲を載せると、そのデッキのテンポは 1.0 に戻る。もう一方のデッキの速度はそのまま。

- `1` / `2` でデッキ A を 0.01 ずつ下げる / 上げる
- `3` でデッキ A を 1.00× に戻す
- `8` / `9` でデッキ B を 0.01 ずつ下げる / 上げる
- `0` でデッキ B を 1.00× に戻す

「1.0 に戻す」でも等速に戻る。

FLX4 のテンポスライダーは、左がデッキ A、右がデッキ B の再生速度を、0.50× から 2.00× のあいだで滑らかに動かす。

## 音量

各デッキの音量。0% から 100%。クロスフェーダーとは別。両方を 100% にできる。クロスフェーダーが中央なら、両方鳴る。片方を 0% にすると、クロスフェーダーがどちら側でも、そのデッキは鳴らない。

曲を載せても、そのデッキの音量は戻らない。スライダーでも FLX4 のチャンネルフェーダーでも、載せた前の値のまま。もう一方のデッキの音量もそのまま。

- `-` / `=` でデッキ A を 5% 下げる / 上げる
- `Shift+,` / `Shift+.` でデッキ B を 5% 下げる / 上げる

「100% に戻す」でも、そのデッキだけ 100% に戻る。

FLX4 のチャンネルフェーダーは、左がデッキ A、右がデッキ B の音量。

## キュー

各デッキのキュー位置は、最初は曲の先頭。

「キュー」を押す。

- 再生中なら、キュー位置へ戻して止まる
- 止まっていて、キュー位置にいないなら、そこへ戻って止まったまま
- キュー位置で止まっているなら、再生する

`Z` がデッキ A、`X` がデッキ B。

`Shift+Z` / `Shift+X` で、今の再生位置をそのデッキのキュー位置にする。

## ジョグ

再生位置だけを動かす。キュー位置とクロスフェーダーは変わらない。曲の端より外には動かない。デッキに曲が載るまでは動かない。

- `[` / `]` でデッキ A を約 1 秒戻す / 進める
- `Shift+[` / `Shift+]` でデッキ A を約 10 秒
- `;` / `'` でデッキ B を約 1 秒戻す / 進める
- `Shift+;`（`+`） / `Shift+'` でデッキ B を約 10 秒

デッキの時間のバーをクリックしても、その位置へ移る。

## クロスフェーダー

中央のフェーダーで、A と B の混ざりを変える。左が A、右が B。各デッキの音量とは別。画面の「位置」がフェーダーの位置、「フェード」がクロスフェーダーによる各デッキの大きさ。

- `←` / `,` で A 側へ
- `→` / `.` で B 側へ
- `Shift+←` / `Shift+→` で大きく動かす
- `Home` / `End` で A 端 / B 端へ

## イコライザー

各デッキの HIGH / MID / LOW。中央が 0 dB。左がカット、右がブースト。バンドの「0 dB」でそのバンドだけ戻す。曲を載せると、そのデッキのイコライザーは中央に戻る。もう一方のデッキのイコライザーはそのまま。

FLX4 の HI、MID、LOW は、左がデッキ A、右がデッキ B。中央が 0 dB。

デッキ A

- `E` / `R` で HIGH を下げる / 上げる
- `D` / `F` で MID を下げる / 上げる
- `C` / `V` で LOW を下げる / 上げる
- `4` で 3 バンドを 0 dB に戻す

デッキ B

- `I` / `O` で HIGH を下げる / 上げる
- `Y` / `U` で MID を下げる / 上げる
- `N` / `H` で LOW を下げる / 上げる
- `7` で 3 バンドを 0 dB に戻す

スライダーにフォーカスがあるあいだは、左右の矢印でそのバンドだけ動く。

## フィルター

各デッキのフィルター。中央はフィルターなし。左がローパスで、さらに左へ動かすと高い音が落ち、低い音が残る。右がハイパスで、さらに右へ動かすと低い音が落ち、高い音が残る。「中央に戻す」でそのデッキだけ中央に戻る。曲を載せても、フィルターは戻らない。

- `T` / `Shift+T` でデッキ A をローパス側 / ハイパス側へ
- `Shift+Q` / `Shift+W` でデッキ B をローパス側 / ハイパス側へ

FLX4 の CFX は、左がデッキ A、右がデッキ B。中央はフィルターなし。
